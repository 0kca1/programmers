유클리드 호제법으로 최대공약수 구하기

두 정수 a, b(a >= b)에 대해 a를 b로 나눈 나머지를 r, 다음엔 b를 r로 나누기 (나누는 수, 나머지)로
계속 바꿔가며 나눠 나머지가 0이 되면, 그때 나누던 수가 최대공약수

> 코드에서는 a가 b보다 작아도 % 에서 자동으로 자리가 바뀜

✅사고포인트

분수의 덧셈을 코드로 옮기는 것
> 통분 a / b + c / d = (a × d + c × b) / (b × d)

기약분수 조건을 최대공약수로 약분하여 한 번에 끝내기
> 분자와 분모를 더 이상 나눌 수 없을 때까지 약분  
> 최대공약수를 빠르게 구하기 위해 유클리드 호제법 사용
