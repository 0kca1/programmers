논문별 인용 횟수 배열 citations가 주어질 때, "h번 이상 인용된 논문이 h편 이상"을 만족하는 h의 최댓값

내림차순으로 정렬 후 위에서 부터 확인/

ex) [3, 0, 6, 1, 5] >> [6, 5, 3, 1, 0]  
citations[0] >= 0 + 1 // 첫 번째 논문은 1번 이상 인용됨? true count++  
citations[1] >= 1 + 1 // 두 번째 논문은 2번 이상 인용됨? true count++  
citations[2] >= 2 + 1 // 세 번째 논문은 3번 이상 인용됨? true count++  
citations[3] >= 3 + 1 // 네 번째 논문은 4번 이상 인용됨? false break

내림차순으로 정렬했으므로 세 번째 논문이 3번 이상 이용됐으면 첫 번째, 두 번째도 3번 이상 인용됐으니까
n편 중 h번 이상 인용된 논문이 h편 이상 인용을 만족하는 h의 최댓값은 true된 조건 중 최댓값이기 때문에 3.
