BFS - Breadth-First Search
너비 우선 탐색

시작 노드를 큐에 넣고 방문 표시, 큐에서 맨 앞으로 노드를 꺼내고  
꺼낸 노드의 인접한 노드 중 아직 방문하지 않은 노드들을 큐에 모두 넣고 

       [1]          1단계: 1 방문 -> 큐: [2, 3]
      /   \         2단계: 2 방문 -> 큐: [3, 4, 5]
     [2]   [3]       3단계: 3 방문 -> 큐: [4, 5, 6]
     / \     \       4단계: 4, 5, 6 순서대로 방문
    [4] [5]   [6]     탐색 순서: 1 -> 2 -> 3 -> 4 -> 5 -> 6


DFS - Depth-First Search
깊이 우선 탐색

시작 노드를 큐에 넣고 방문 표시, 

        [1]          1단계: 1에서 2로 깊게 이동
       /   \         2단계: 2에서 4로 깊게 이동 (4는 막다른 길)
     [2]   [3]       3단계: 2로 되돌아와서 5로 이동
     / \     \       4단계: 1로 되돌아와서 3 -> 6으로 이동
    [4] [5]   [6]     탐색 순서: 1 -> 2 -> 4 -> 5 -> 3 -> 6
